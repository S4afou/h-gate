# Dataset: ISCX-URL2016

The notebook expects the ISCX-URL2016 CSVs (the `All.csv` / per-class exports) in the
working directory. The dataset is not redistributed here.

- Source: Canadian Institute for Cybersecurity, University of New Brunswick
- Page: https://www.unb.ca/cic/datasets/url-2016.html
- Contents: 36,707 labelled URLs across five classes (benign, defacement, malware,
  phishing, spam), with lexical and host-based features
- Access: request from the CIC site, free for research use
- Citation: Mamun et al., "Detecting Malicious URLs Using Lexical Analysis", NSS 2016

The notebook's section 1 expects the CSV files next to the notebook. Column names differ
slightly between the CIC releases, so check the mapping in that section before rerunning.
